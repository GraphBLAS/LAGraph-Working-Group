Do we use `GrB_Scalars` where possible, for all input/output scalars?  Or just
in some methods?

Continue discussing using an LAGraph descriptor to pass in details of which
hardware to use.  This could be handled with the GraphBLAS
`GxB_Context` object.

Tim Davis would like to ask if we can ditch the "vanilla" idea and simply
require SuiteSparse:GraphBLAS and its GxB extensions.  Reasons: (1) keeping the
"vanilla" becomes harder as SuiteSparse:GraphBLAS improves, (2) there is no
other usable high-performance GraphBLAS library, and (3) there is no active
GraphBLAS C API committee.
